The ALTER passes.
The app still breaks.

Built by Rushil Shah Software Engineer · Visa Inc

A valid database migration can still break consumers of the old schema.

Why rehearsal matters

Passing DDL is only the first signal.

PostgreSQL accepting a migration does not prove that code using the old schema will work. Services, reports, and integrations may still reference changed objects. Here, a dependent view survives the rename while a direct query fails. The agent checks both before a person decides on the public-schema change.

The migration under test
orders.status → orders.order_status

The staging rename succeeds; a direct o.status query fails.
